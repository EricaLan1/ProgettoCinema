# Siediti & Guarda 🎬

**A Cinema Management and Experience Web Application**

Siediti & Guarda is a collaborative web application developed by a team of three people to simulate the digital experience of a modern cinema.

The application provides a public area for browsing movies and screenings, a personal area for registered users, and an administrative dashboard for managing the cinema's main content and data.

##  Main Features

### Public Area
- Homepage with featured movies and promotional banners.
- Movie listings with search and genre filters.
- Upcoming movies and screening information.
- Membership, offers and Cinefans cards.

### User Area
- Personal dashboard.
- Purchased tickets and menus overview.
- Membership points and card information.
- Personal data management.
- Shopping cart and simulated purchase flow.

### Administration Area
- Movie management.
- Screening schedule management.
- Offers management.
- User search and role management.

## 👩‍💻 Team & My Contribution

The project was developed collaboratively by a team of three people.

My main responsibilities included:
- Developing frontend pages and components using Thymeleaf, HTML, CSS and JavaScript.
- Working on the visual design and graphical elements of the application.

## ⚠️ Project Scope

This is a demonstration project. The purchase flow is simulated and no real payments are processed.

Some interface options, such as marketing preferences, are currently visual elements and are not fully functional.

# Siediti & Guarda 🎬

**Applicazione web per la gestione e l'esperienza digitale di un cinema**

Siediti & Guarda è un'applicazione web collaborativa sviluppata da un team di tre persone per simulare l'esperienza digitale di un cinema moderno.

L'applicazione offre un'area pubblica per consultare film e programmazioni, un'area personale dedicata agli utenti registrati e una dashboard amministrativa per gestire i principali contenuti e dati del cinema.

##  Funzionalità principali

### Area pubblica
- Homepage con film in evidenza e banner promozionali.
- Elenco dei film con ricerca e filtri per genere.
- Film in programmazione e prossime uscite.
- Membership, offerte e carte Cinefans.

### Area utente
- Dashboard personale.
- Riepilogo di biglietti e menu acquistati.
- Punti membership e informazioni sulle carte.
- Gestione dei dati personali.
- Carrello e simulazione del flusso di acquisto.

### Area amministrativa
- Gestione dei film.
- Gestione delle programmazioni.
- Gestione delle offerte.
- Ricerca degli utenti e gestione dei ruoli.

## 🛠️ Tecnologie utilizzate

| Categoria | Tecnologie |
|---|---|
| Linguaggi | Java 17, JavaScript |
| Backend | Spring Boot 3.5.4, Spring Security |
| Persistenza | Spring Data JPA, Hibernate |
| Database | MySQL |
| Frontend | Thymeleaf, HTML5, CSS3, Bootstrap 5 |
| Build | Maven |
| Server | Tomcat Embedded |
| Altri strumenti | Git, GitHub, IntelliJ IDEA, Eclipse |

## 👩‍💻 Team e mio contributo

Il progetto è stato sviluppato in collaborazione da un team di tre persone.

Le mie principali attività hanno riguardato:
- Sviluppo delle pagine e dei componenti frontend con Thymeleaf, HTML, CSS e JavaScript.
- Cura del design e degli elementi grafici dell'applicazione.
- Supporto al team con alcune correzioni al codice backend.
- Collaborazione alle attività di integrazione e sviluppo del progetto.

##  Collaborazione e versionamento

Il team ha utilizzato Git e GitHub per il versionamento del codice sorgente e la collaborazione.

Lo sviluppo è stato svolto utilizzando IntelliJ IDEA ed Eclipse, con operazioni Git come pull, push e merge per sincronizzare e integrare le modifiche al codice.

## ⚠️ Ambito del progetto

Si tratta di un progetto dimostrativo. Il flusso di acquisto è simulato e non vengono effettuati pagamenti reali.

Alcune opzioni dell'interfaccia, come quelle relative alle preferenze di marketing, sono attualmente elementi grafici e non risultano completamente funzionali.
